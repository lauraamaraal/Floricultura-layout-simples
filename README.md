# 🌸 Landyng page Floricultura - Projeto de Estudo

> Projeto desenvolvido para praticar HTML e CSS, criando um site responsivo para uma floricultura fictícia.

---

## 📖 Sobre o Projeto

Este é um projeto pessoal desenvolvido com o objetivo de praticar e consolidar conhecimentos em **desenvolvimento front-end**. O site simula uma floricultura chamada "Flor e Amor", onde são aplicados conceitos fundamentais de programação web.

### 🎯 Objetivos de Aprendizado

- ✅ Praticar **HTML semântico** e estruturação de páginas
- ✅ Aplicar **CSS moderno** com Flexbox e Grid Layout
- ✅ Desenvolver um **design responsivo** para todos os dispositivos
- ✅ Utilizar **Google Fonts** para tipografia personalizada
- ✅ Criar uma **interface atrativa** e funcional
- ✅ Aplicar boas práticas de **organização de código**

---

## 🛠️ Tecnologias Utilizadas

| Tecnologia | O que pratiquei |
|------------|-----------------|
| **HTML5** | Estruturação semântica, tags, links, imagens |
| **CSS3** | Flexbox, Grid, responsividade, animações, seletores |
| **Google Fonts** | Fontes Great Vibes e Cutive Mono |

---

## 📋 Funcionalidades Implementadas

### 📌 Estrutura do Site

1. **Cabeçalho Fixo**
   - Navegação com links âncora
   - Efeito hover nos links
   - Design minimalista

2. **Seção Hero**
   - Título principal com fonte cursiva
   - Subtítulo
   - Layout centralizado

3. **Catálogo de Flores**
   - Cards com imagens, nome, descrição e preço
   - Efeito hover com zoom e elevação
   - Botão "Comprar" estilizado
   - Layout responsivo com colunas

4. **Sobre Nós**
   - História da empresa
   - Valores em lista estilizada
   - Especialidades em grid
   - Imagens ilustrativas

5. **Saiba Mais**
   - Localização com endereço fictício
   - Horário de funcionamento
   - Links para redes sociais
   - Ícones personalizados
